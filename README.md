# about me 

[Simple site](https://dmitriev-dmitrii.github.io/about-me) about me, my experience, and pet projects.

## Build Setup
master branch - auto deploy generate nuxt
vue 2 (nuxt) legacy
ui - [gitlabUI](https://design.gitlab.com/components)
node version 16

json load from github-gist

```bash
# install dependencies
$ npm install

# serve with hot reload
$ npm run dev

# generate static project
$ npm run generate

```
